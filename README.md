# Social Listening Dashboard

A comprehensive dashboard for monitoring social media mentions, sentiment analysis, and brand tracking across platforms.

## Features

- Track keyword mentions across various platforms
- Sentiment analysis
- Source tracking
- Time-based analysis
- Filtering capabilities
- Data visualization

## Getting Started

### Prerequisites

- Node.js (version 16.x or higher)
- npm or yarn

### Installation

1. Clone the repository
   ```
   git clone https://github.com/MazRadwan/social.git
   cd social
   ```

2. Install dependencies
   ```
   npm install
   # or
   yarn install
   ```

3. Run the development server
   ```
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Recharts for data visualization
